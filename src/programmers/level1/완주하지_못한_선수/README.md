# 완주하지 못한 선수

## 문제 요약
마라톤에 참여한 선수들의 이름이 담긴 배열 `participant`와  
완주한 선수들의 이름이 담긴 배열 `completion`이 주어진다.

완주한 선수는 참여한 선수보다 항상 1명 적다.

참여자 중에서 완주하지 못한 선수의 이름을 반환하는 문제이다.

단, 동명이인이 존재할 수 있다.

예시  
`participant = ["leo", "kiki", "eden"]`  
`completion = ["eden", "kiki"]`

→ `leo`

---

## 풀이 아이디어

완주한 선수들을 기준으로 HashMap에 이름과 등장 횟수를 저장한다.

이후 참가자 배열을 순회하면서

- HashMap에 해당 이름이 없거나
- 카운트가 0이라면

그 선수는 완주하지 못한 선수이므로 바로 반환한다.

만약 HashMap에 존재한다면 카운트를 1 감소시켜  
동명이인 상황도 처리한다.

---

## 핵심 로직

1. `HashMap<String, Integer>` 생성
2. `completion` 배열을 순회하면서
    - 선수 이름을 key로
    - 등장 횟수를 value로 저장
    - `getOrDefault()`를 사용해 카운트 증가
3. `participant` 배열을 순회하면서
    - HashMap에서 해당 선수의 카운트를 확인
4. 카운트가 `0`이라면
    - 완주하지 못한 선수이므로 바로 반환
5. 카운트가 있다면
    - `-1` 하여 동명이인 상황 처리

---

## 복잡도

시간 복잡도 : O(N)
