# 전화번호 목록

## 문제 요약
전화번호 목록이 담긴 배열 `phone_book`이 주어진다.

어떤 번호가 다른 번호의 접두어(prefix)인 경우가 존재하면 false,  
그렇지 않으면 true를 반환하는 문제이다.

예시  
`["119", "97674223", "1195524421"]` → `false`

---

## 풀이 아이디어
처음에는 모든 번호를 서로 비교하는 방식으로 접근했다.

하지만 이 경우 이중 반복문을 사용하게 되어 시간복잡도 O(n²)가 발생하고,  
데이터가 많아지면 시간 초과가 발생한다.

그래서 접근 방식을 바꿔서 다른 번호를 비교하는 것이 아니라  
현재 번호의 접두어가 존재하는지 확인하도록 했다.

이를 위해 HashMap에 모든 전화번호를 저장한 뒤,  
각 문자열의 접두어를 잘라가며 map에 존재하는지 확인한다.

---

## 핵심 로직
1. 모든 전화번호를 HashMap에 저장
2. 전화번호 배열을 순회하면서
3. 각 번호의 접두어를 substring(0, i)로 생성
4. 해당 접두어가 map에 존재하면 false 반환
5. 끝까지 문제가 없으면 true 반환

---

## 복잡도

기존 풀이 (이중 for문) : O(n²)  
개선 풀이 (HashMap) : O(n * m)  
(m = 문자열 길이)

---

## 개선 포인트
초기에는 이중 반복문으로 모든 문자열을 비교하여 해결하려 했지만  
시간복잡도 문제로 실패했다.

이후 HashMap을 활용하여 탐색을 빠르게 만들고,  
문자열 자체를 비교하는 것이 아니라 접두어를 잘라서 존재 여부를 확인하는 방식으로 개선했다.
